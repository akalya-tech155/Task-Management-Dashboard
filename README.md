# Task Management Dashboard

## Project Description
A simple web application to manage tasks.

## Features
- Add Task
- Edit Task
- Delete Task
- Filter Tasks
- Set Task Priority

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run
1. Clone the repository
2. Open index.html in a browser
3. Start managing tasks
